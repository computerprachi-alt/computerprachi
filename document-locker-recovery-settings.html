Recovery Settings

Recovery Code

Generate a strong, single-use Recovery Code and save it in a secure password manager or another private place. It is displayed only in this session when you generate it. The server stores only its hash. Regenerating replaces and invalidates the previous code. Never share this code.

Change registered email

After recovering your password and signing in, enter a new reachable email address here. Supabase will send its email-change verification message. The new address is not active until verification is completed.


If you lose access to both your email and phone and cannot use this code, use Admin-Verified Recovery. Mobile OTP is unavailable.
