# Computer Prachi — Automatic Jobs / Results / Admit Card Updates

## What is automatic now?
GitHub Actions runs the updater every 30 minutes. It reads the public category lists from SarkariResult.com.cm and refreshes the Computer Prachi pages.

Updated sections:
- Latest Jobs
- Results
- Admit Card
- Answer Key
- Admission
- 10th / ITI
- Outsourcing Jobs
- Syllabus
- Documents
- Latest Update

## Important
This does NOT require payment credentials or any private API key.

## GitHub setup
1. Upload/replace these files in your Computer Prachi GitHub repository.
2. Make sure `.github/workflows/auto-update.yml` is present.
3. Open GitHub → Actions → "Computer Prachi Automatic Updates".
4. Run "Run workflow" once manually to test it.
5. After that, the scheduled workflow runs every 30 minutes (GitHub may delay scheduled jobs).
6. GitHub Pages then publishes the committed HTML changes.

## Safety
The updater refuses to overwrite the site when fewer than two primary categories (Jobs, Results, Admit Cards) can be parsed. This helps prevent a temporary source/site error from wiping the lists.

## Source
The updater currently uses https://sarkariresult.com.cm/ as the content source. Verify each notice against the relevant official department notification before relying on it.
