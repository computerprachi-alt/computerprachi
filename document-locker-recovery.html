Account Recovery

Option 1: Recovery Code

Use the Recovery Code you saved earlier. A valid code is single-use. After verifying, set a new password. To protect accounts, the same generic response is shown for valid and invalid codes.

Option 2: Admin-Verified Recovery

If you have lost access to both registered contact methods and do not have your Recovery Code, submit a request. Personal details alone are not proof of ownership. An authorized administrator must independently verify the account. Do not submit identity documents through this form.

Requests expire after 30 days. Rejected and expired identity details should be deleted after 30 days under the recovery retention policy. Email OTP remains available from the Login page. Mobile OTP is unavailable.
